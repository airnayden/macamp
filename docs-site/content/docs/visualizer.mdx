MacAMP displays a compact spectrum in the macOS player and a dedicated visualizer sheet on iOS.

---

## Modes

Both players offer four modes:

![The four compact spectrum modes: particles, aurora, bars and oscilloscope](/assets/mac-visualizer-modes.png)

| Mode | Description |
|---|---|
| **Bars** | Classic frequency-spectrum bar graph, accent-colored |
| **Oscilloscope** | Waveform trace of the audio signal |
| **Particles** | Particle system driven by the spectrum amplitude |
| **Aurora** | Flowing aurora-style gradient animated by the spectrum |

## macOS — compact spectrum

Look for the spectrum beside the volume controls in the [player bar](./playback#the-player-bar). It also appears in the expanded player. Click the spectrum to cycle through the modes, or choose a mode in **Settings > Visualizer**.

Use **Show Visualizer in Player Bar** in that section to show or hide both compact spectra.

---

## iOS — visualizer sheet

From the Now Playing screen, tap the **Visualizer** button (waveform circle icon) in the toolbar.

Use the mode buttons at the bottom of the sheet. Tap **Done** to return to Now Playing.

![iOS visualizer sheet](/assets/ios-visualizer-sheet.png)

---

## Choosing the mode in Settings

**Settings > Visualizer > Default Mode** changes the current mode on both platforms. On macOS, MacAMP also remembers this choice for its next launch.
