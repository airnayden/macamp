# MacAMP Docs

The MacAMP documentation site — a [Fumadocs](https://fumadocs.dev) instance on Next.js,
configured for [Static Export](https://nextjs.org/docs/app/guides/static-exports) so the whole
site builds to plain HTML in `out/` and can be hosted anywhere. **No server is required.**

Requires **Node 22+**.

```bash
npm ci          # install (uses the committed lockfile)
npm run dev     # dev server on http://localhost:3000
npm run build   # static export -> out/
npm start       # serve the built out/ directory locally
npm run types:check
```

## Layout

| Path                      | Description                                                          |
| ------------------------- | -------------------------------------------------------------------- |
| `content/docs/`           | The MDX pages. `index.mdx` is the guide landing page.                |
| `content/docs/meta.json`  | Sidebar order (`pages` array) and section title.                     |
| `public/assets/`          | Screenshots. Reference them from MDX as `/assets/<name>.png`.        |
| `lib/source.ts`           | Content source — `defineDocs` (Macro API) + [`loader()`](https://fumadocs.dev/docs/headless/source-api). |
| `lib/shared.ts`           | Site name, nav title, docs base route.                               |
| `lib/layout.shared.tsx`   | Shared layout options (nav).                                         |
| `app/(docs)/`             | Docs layout and the catch-all page, served from the site root.       |
| `app/api/search/route.ts` | Search index, pre-rendered via `staticGET` (Orama static client).     |

## Look and feel

The docs share the marketing site's synthwave theme (dark-only, forced in `components/provider.tsx`).

- **Colours, fonts, sidebar, prose, cards:** `app/global.css`. The Fumadocs `--color-fd-*` tokens are
  mapped to the app's palette (canvas `#0D0221`, pink `#FF2975`, cyan `#4DE2F0`); everything else hooks
  onto Fumadocs' stable IDs (`#nd-sidebar`, `#nd-page`, `#nd-toc`, `#nd-subnav`).
- **Fonts:** self-hosted in `app/fonts/` (Archivo, Inter, JetBrains Mono, Mr Dafoe) via `next/font/local`,
  so the build needs no network access.
- **Header, sidebar card, footer links:** `components/brand.tsx` and `lib/layout.shared.tsx`.
- **Guide home banner:** `components/guide-hero.tsx`, used as `<GuideHero />` in `content/docs/index.mdx`.
- **URLs:** `docsUrl` (docs.macamp.si), `websiteUrl` (macamp.si), `githubUrl` (github.com/airnayden/macamp) and the `author` credit live in `lib/shared.ts`.

## Conventions

- **Adding a page:** drop a `.mdx` file in `content/docs/` with `title` + `description`
  frontmatter, then add its filename (without extension) to `pages` in `meta.json`.
  A page missing from `pages` is still routable but is appended after the listed ones.
- **Images** live in `public/assets/` and are referenced root-relative (`/assets/foo.png`),
  not relative to the MDX file.
- **Cross-page links** use relative paths (`./install`); `createRelativeLink` resolves them
  against the page tree. `trailingSlash` is enabled so these resolve correctly in the
  static export.
- `.source/` is generated by `fumadocs-mdx` at build time and is **not** committed.
